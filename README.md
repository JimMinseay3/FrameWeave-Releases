# FrameWeave

Windows 安装程序、版本说明和更新清单的公开发行渠道。

开发仓库保持私有。本仓库不提供 FrameWeave 的业务开发源码。

## 下载与更新

在 Releases 下载最新的 `FrameWeave-版本-windows-x64-setup.exe`。
首次安装后，在软件的「设置 → 软件更新」检查和下载后续版本，无需 GitHub 账号。

升级前关闭工作台窗口并停止服务，再运行新版安装程序。默认用户数据目录独立保存，正常覆盖升级会保留账号、素材、配置和成片。

首次从 0.4.x 切换到公开发行版，需要手动安装一次新版，后续即可使用公开更新源。

## 分发与许可

FrameWeave 自有软件的许可见 SOFTWARE-LICENSE.txt；下载公开安装包不表示业务源码采用开源许可证。
第三方组件各自适用原许可证，完整许可证和来源说明随安装包分发，不受自有软件许可条款覆盖。

业务 Python 模块编译分发可以提高代码还原难度，不能保证无法逆向。该版本不提供软件激活限制，安装包可被公开下载。

当前目标平台为 Windows 10 2004 及以上 x64 / Windows 11 x64。安装程序尚未进行发布者代码签名。
